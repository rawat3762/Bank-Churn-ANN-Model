# Bank Customer Churn Prediction using ANN 💳

This project demonstrates the implementation of an Artificial Neural Network (ANN) to predict whether a bank customer will leave (churn) or not.

## 📌 Project Overview

Customer churn prediction is a crucial problem in the banking sector. In this project, an ANN model is built to identify customers who are at risk of leaving the bank.

The model learns patterns from historical customer data and performs binary classification (churn / not churn).

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* TensorFlow / Keras

## 📊 Dataset

The dataset contains bank customer details such as:

* Credit Score
* Geography
* Gender
* Age
* Balance
* Number of Products
* Estimated Salary
* Exited (Target Variable)

## ⚙️ Steps Performed

* Data loading and exploration
* Data preprocessing and cleaning
* Encoding categorical variables
* Feature scaling using StandardScaler
* Splitting dataset into training and testing sets
* Building ANN model
* Model training and prediction
* Model evaluation using accuracy score

## 🎯 Result

The model successfully predicts customer churn with good accuracy using ANN.
